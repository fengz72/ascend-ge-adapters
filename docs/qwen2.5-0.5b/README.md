## 维护约定

- 使用说明维护在模型 README；配置维护在 YAML；实验结论维护在对应报告，其他文档通过链接引用。
- 历史报告只代表所标注日期、版本和输入下的结果，不是当前配置快照。后续结论在本索引更新入口，不在每篇旧报告重复写当前默认值。
- 同一主题的后续结果追加到原报告及附录；新增主题再单独建文档。保留成功、失败、中断和受干扰的记录，不新增 CSV 汇总。
- 文件名使用英文，正文使用中文。原始运行产物保存在 work，文档保存结论、结果表格和追溯路径。
