日期：2026-10-24。A5 默认启用 NZ；batch 固定 16，全部普通性能关闭 profiling。

## 测量口径

- 使用 850-a5 / hejun-cann910-stream 的空闲逻辑卡 3；逐次保存运行前后设备状态。
- QPS 为业务样本/秒；P99 包含 H2D、描述符、执行和同步，不含服务排队及组 batch 等待。
- 同一 100 组变长输入池，SHA256：`21defc288cc9848d6f1f71f8a8c6d900327963431e57e77125274b5f5fc8c85b`。完整覆盖 89 种 shape/实例后计时。
- 已完成48个成功扫描点，每点1000调用、seed42；另有两次恢复控制复测。编译和预热不计入性能。本次未执行候选3×3000调用确认。
- GE 核预算、planner 核预算与 attention 启动核数一致；使用已验证的无缓存算子核数变体。
- 在P99 < 60 ms的成功扫描点中比较QPS；3–5实例综合表现按三个实例数的QPS等权平均，同时列出各点P99。下文使用单轮扫描值，不将其称为多轮中位数。
- NZ 使用标准 CANN 自定义融合 Pass 安装目录加载，无 LD_PRELOAD；每实例编译日志核对 169 个权重转换。

## 推荐最优配置

本次将 **NZ、16|32、batch16、3实例** 确定为A5推荐最优配置。配置结构整理后，参数统一维护在
`models/qwen2.5-0.5b/config/model.yaml` 的 `platforms.a5`，batch 继承公共配置；A5默认依赖启用 `weight_nz`。

该点在已完成的48个成功扫描点中QPS最高，业务QPS **2768.499**、P99 **19.475 ms**，低于60ms。
同一限核下，3/4/5实例QPS分别为2768.499/2749.840/2692.670，等权平均 **2737.003**，也是已测限核配置中最高。
因此，峰值吞吐与3–5实例综合表现均选择16|32，默认实例数设为3。

验证范围：以上性能来自每点1000调用、seed42、关闭profiling的扫描；100case/12800评分与ND基线逐位一致。
测试期间因卡被其他任务占用而结束，本次没有完成候选三轮长窗口确认及新的默认入口性能复验。
该配置是当前已测范围内的最优选择，不代表已穷尽全部可能组合。
