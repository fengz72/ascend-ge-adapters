# BGE `force_fp16` 8/10/12 实例无 profiling 复测

2026-10-27 在 100 机器 `hejun-cann9-bge`、逻辑设备 10（PCI `0000:89:00.0`）完成。沿用原始 ONNX、GE Session mode=0、`force_fp16`、每算子 `12|24` 核、固定 `case-0000`，仅改变实例数。每轮预热后测量≥60秒和≥10000个成功请求，计时包含 H2D、GE 同步和全量 D2H。按 8→10→12→12→10→8→12→10→8 串行执行，每档三轮；第二、第三轮使用新的 seed。**所有计划均为 `profiling=false`、`dump=false`，没有采集 profiling。**

针对前次30秒短轮的环境疑问，本次在宿主侧每约3.3–3.5秒采集目标/邻芯片 `npu-smi proc-mem` 和全机 load average，并用宿主 `/proc/<PID>/cgroup` 将 NPU 进程归属到本容器。监控不采集算子时间线，不属于 profiling。九轮均有17–18次测量窗口内采样，最大间隔<5秒；每次目标芯片恰有一个 `ge_runtime` PID且归属本容器，邻芯片无进程，监控命令无错误。各轮前后设备门禁清空、受管作业 exit 0，输入/模型/二进制身份及逐请求性能重算通过，错误数均为0。这些采样大幅降低外部进程干扰的疑虑，但仍不能在采样间隙提供连续独占证明。

三轮 QPS 中值：8实例 **831.563**、10实例 **856.153**、12实例 **787.483**。10实例相对8实例为 **+2.957%**，低于预设的 `max(3%, 八实例轮间极差/中值5.000%, 十实例轮间极差/中值2.402%) = 5.000%` 判断门槛。12实例相对8实例为 **−5.301%**，自身三轮极差/中值达 **12.799%**。p99中值依次为19.299、23.764、36.764ms；不同实例数的容量点不是同固定到达率的延迟 A/B，不把该差异解释为单请求的同负载延迟收益。本项目暂无业务 p99 硬上限，但10/12实例长尾变大需要保留。HBM最高仅11.4/64GiB，未触及显存容量上限。

因此，本次结果显示10实例有小幅吞吐观察值，但**未超过预设波动/显著性门槛，不接纳OPT-016**；12实例吞吐中值下降且波动较大，**不接纳OPT-017**。当前已验收交付仍为原图FP32八实例半核配置。此前 `force_fp16` 八实例的五例完整输出精度已通过，但其第三轮 FP32/FP16 同卡正式对照和600秒稳定性仍未完成；10/12实例本次只测性能，没有做新实例数的五例完整输出、随机回放或稳定性，因此不能将FP16设为最终交付。上述结论只覆盖本次8/10/12实例与固定case0，不宣称更大实例数或其它输入分布的绝对最优点。
