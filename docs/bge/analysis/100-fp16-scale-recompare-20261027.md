# BGE `force_fp16` 8/10/12 实例复测（2026-10-27）

## 条件与目的

在 100 机器 `hejun-cann9-bge` 容器的逻辑设备 2（NPU1/Chip0，PCI `0000:99:00.0`）上，复测当前 BGE 原始 ONNX 的实例数与 QPS。GE Session 使用 `graph_run_mode=0`、内部 `precision_mode=force_fp16`、每算子 `aicore_num=12|24`；不改写 Slice，不加载自定义融合插件，外部七个 INT64、一个 FP32 输入及 FP32 输出契约保持不变。唯一变量是 8、10、12 个独立实例。

每个配置分别运行固定 `case-0000` 和五例等概率有放回随机回放，各 3 轮、每轮至少 60 秒及 10000 个成功请求。轮次 seed 为 2051/2052/2053；顺序依次为 `fixed 8→10→12, random 12→10→8`、`random 8→10→12, fixed 12→10→8`、`fixed 10, random 10, fixed 8, random 8, fixed 12, random 12`。闭环负载每实例单在途；计时含 H2D、描述符设置、GE 执行及同步、全量 D2H，不含文件读取、CPU 参考比对或服务排队。全部关闭 profiling、dump 和输出归档。p99 仅描述各配置自己的容量点；本需求未提供业务 p99 上限。

## 正式结果

QPS 为成功请求数除以实际测量窗口时长。表中按轮次列出原始 QPS，汇总取三轮中位数；“波动”是 `(最大QPS−最小QPS)/中位QPS`。p99 也按轮次列出，不把三轮 p99 的中位数当成合并请求 p99。

|---|---:|---:|---:|---:|---:|---:|
|固定 `case-0000`|8|807.326 / 806.469 / 860.317|807.326|6.670%|19.718 / 20.299 / 11.297|8689|
|固定 `case-0000`|10|867.413 / 884.177 / 891.613|884.177|2.737%|21.257 / 14.262 / 13.766|10055|
|固定 `case-0000`|12|840.609 / 903.724 / 851.169|851.169|7.415%|35.403 / 14.734 / 33.053|11413|
|五例随机|8|865.369 / 861.592 / 843.656|861.592|2.520%|11.935 / 15.321 / 13.505|8681|
|五例随机|10|903.582 / 730.640 / 905.983|903.582|19.405%|19.285 / 31.624 / 11.967|10047|
|五例随机|12|879.703 / 850.007 / 862.495|862.495|3.443%|35.958 / 33.133 / 36.856|11417|

18 轮均达到窗口与请求数门槛，均 0 请求错误；性能事件独立重算、输入身份、模型/二进制/配置身份、前后双芯片门禁全部通过。每轮轮内 14～21 个资源样本，采样间隔最大约 12.4 秒；目标芯片采样时最多一个进程，邻芯片始终未见进程。Host 1 分钟 load average 在各作业间变化很大，且与 QPS 变化不单调。随机 10 实例第 2 轮的 730.640 QPS 主要表现为 GE 执行段均值增至 13.508 ms；第 1 轮为 10.928 ms。当前证据没有证明外部 NPU 占用，也无法排除采样间隔内的短暂干扰或其它环境因素，故保留该轮而不事后剔除。

## 比较与决定

预设判据是吞吐差幅超过 `max(3%, 基线三轮相对极差, 候选三轮相对极差)` 才认为超出测量波动；固定与随机场景独立比较。

|同场景对照|固定 `case-0000`|五例随机|
|---|---:|---:|
|10 相对 8|+9.519%，门槛 6.670%；本批固定场景增益成立|+4.874%，门槛 19.405%；不成立|
|12 相对 10|−3.733%，门槛 7.415%；无稳定优势|−4.547%，门槛 19.405%；无稳定优势|
|12 相对 8|+5.431%，门槛 7.415%；不成立|+0.105%，门槛 3.443%；不成立|

维持用户指定的 **10 实例**运行配置。它已在[此前专项验收](100-fp16-ten-selection-20261027.md)通过 2009 次五例完整输出、双场景正式轮和 600 秒随机稳定性；本次性能轮为减少测量开销关闭了输出归档，不重复充当精度压力验收。12 实例既未证实更高吞吐，也尚未完成新实例数的完整输出与稳定性验收，因此不接纳。随机场景无法证明 10 比 8 更快；不能用两轮约 904 QPS 的结果掩盖第 2 轮低值，也不能把固定场景收益外推到实际业务流量。

原始作业名是 `fp16-compare-d2-r{1,2,3}-{fixed,random}{8,10,12}-20261027`，逐作业计划、事件、资源、性能、身份、门禁与状态仍在项目根 `work/`。可核查的逐轮字段、SHA256、设备进程和资源摘要见[机器可读证据](../evidence/20261027-fp16-scale-recompare.json)。用新作业名复现例如：

```bash
cd /export/home/ext.hejun23/workspace/bge-opt-100
python3 tools/run_one.py --formal --config forcefp16-half10 --timeout 500 \
  my-fp16-fixed10 -- --instances 10 --cores '12|24' \
  --precision-mode force_fp16 --seconds 60 --max-seconds 300 \
  --requests 10000 --seed 2053 --case-id case-0000
```

五例随机回放去掉 `--case-id case-0000`，并使用新作业名。再次测试前应重新确认设备独占；本次 QPS 仅代表给定五例和当前闭环压力，不代表有排队/预处理的服务端到端吞吐。
