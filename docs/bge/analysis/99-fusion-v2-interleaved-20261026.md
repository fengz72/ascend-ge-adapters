# 99 融合 V2 与固定 case 交错对照

结论：融合 V2 的随机五例完整分数与 Top-10 全部通过原阈值；固定 case 交错两轮里融合 V2 与原图互有高低，轮次长短与交错次序不足以证实稳定收益。

## 口径

99 机器，单实例全核、FP32、GE `mode=0`；计时含输入输出搬运。随机场景是五例 2000 请求的完整分数，固定场景是同一 case 的原图/融合 V2 交错两轮。两组共用同一份冻结输入与原阈值（cosine ≥ 0.9999、relative L2 ≤ 0.001、最大绝对误差 ≤ 0.001）。

## 结果

- 随机五例 2000 请求：完整 10112 维分数与 Top-10 全部通过原阈值，数值见附录表。
- 固定 case 交错两轮：融合 V2 与原图各有胜负，两轮 QPS 见附录表。
- 轮次长短与交错次序不足以证实稳定收益。
- 两份 GE profiling 已采集；逐算子归因仍在离线核对，不用节点数直接推断 p99 原因。

## 判定

固定 case 的单轮 QPS 差异不构成融合 V2 的吞吐收益证据；引用该对照时只能当作两轮交错观测，不能外推为稳定增益。随机五例的压力轮满足原有精度门槛，压力数字不作性能值。
