# OPT-002：48处residual Add与LayerNorm融合为CANN AddLayerNorm（V1）

## 1. 身份与状态

2026-10-26；主控分配，SE/开发实现或配置，测试独立核对。父版本为原FP32全核单实例，GE Session mode=0，逻辑设备10（NPU5/Chip0，PCI0000:89:00.0）。不接纳：纯性能运行外层exit125/background_children，生命周期失败，性能结果无效。

## 2. 问题与假设

口径同 [README.md](README.md) 第 2 节。本项检验 48 处残差 Add+LayerNorm 融合为 CANN AddLayerNorm 能否提高包含输入输出搬运的成功吞吐；不由算子数量或数据类型推算收益。

## 3. 实现与回退

原FP32模型不变；自定义GE pass在builtin fusion后匹配encoder残差结构，48处改用CANN AddLayerNorm。插件V1 SHA256=8767095f04348ed6097c769d71909421409397cedef534c4c7650d61df6cfff5。外层LD_PRELOAD覆盖了基线tcmalloc并传给Python子进程，这个环境差异也使性能不可比。

源模型/权重、样例、expected 与阈值不变（口径见 [README.md](README.md) 第 2 节）。测量 binary SHA256=8efca50a62a7f569032345259d6e7813da428023903e4674d77de92bc7ac630d。回退到原 FP32、全核、instances=1、不加载插件。

## 4. 比较条件

口径同 [README.md](README.md) 第 2 节。本节为 30 秒且 ≥2000 请求的搜索，capture/profiling=false；压力采集另做，采集数字不作性能值；相对差值只是搜索观察，无统计显著性声明。
