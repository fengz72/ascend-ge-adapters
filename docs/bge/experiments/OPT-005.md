# OPT-005：原FP32全核双实例闭环并发

## 1. 身份与状态

2026-10-26；主控分配，SE/开发实现或配置，测试独立核对。父版本为原FP32全核单实例，GE Session mode=0，逻辑设备10（NPU5/Chip0，PCI0000:89:00.0）。暂作为中间有效候选；最终接纳由冻结复测和稳定性决定。

## 2. 问题与假设

口径同 [README.md](README.md) 第 2 节。本项检验原 FP32 全核双实例闭环并发能否提高包含输入输出搬运的成功吞吐；不由算子数量或数据类型推算收益。

## 3. 实现与回退

原始FP32图、precision_mode=must_keep_origin_dtype、mode0、全核不变；instances=2，每实例独立GE图/stream/缓冲，单实例一个在途请求。不加载融合库，不改业务batch1。

源模型/权重、样例、expected 与阈值不变（口径见 [README.md](README.md) 第 2 节）。测量 binary SHA256=8efca50a62a7f569032345259d6e7813da428023903e4674d77de92bc7ac630d。回退到原 FP32、全核、instances=1、不加载插件。

## 4. 比较条件

口径同 [README.md](README.md) 第 2 节。本节为 30 秒且 ≥2000 请求的搜索，capture/profiling=false；压力采集另做，采集数字不作性能值；相对差值只是搜索观察，无统计显著性声明。

## 5. 基线与优化后结果

|指标|首次可信FP32单实例基线|本候选搜索|变化|

2001个cohort完整输出全部PASS（2000窗口完成+1尾部），10个instance×case组合最少159次；full max abs=0.00021588802337646484、relativeL2=0.0004473780329645363、min cosine=0.9999999058732865。

## 6. 分析与决策

单轮30秒搜索8097个窗口成功、1个尾部，零错误；不能将+53.95%的搜索观察直接当最终交付收益。继续与4/8实例有限比较，未被选中的中间点不单独进行10分钟稳定性。

暂作为中间有效候选；最终接纳由冻结复测和稳定性决定。汇总规则见 [README.md](README.md) 第 2 节。
