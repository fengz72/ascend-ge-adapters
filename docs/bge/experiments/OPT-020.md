# OPT-020：按结构匹配 FusedInferAttentionScore

## 1. 身份与状态

2026-10-29 完成。父配置为 OPT-019 的 BGE 原始 ONNX、GE mode=0、`force_fp16`、`12|24` 核和 10 实例。当前状态：结构匹配与正确性通过，接纳为隔离实验 pass 的实现；本项不主张新增吞吐收益。当次修改仅在隔离副本 `merge-review-20261029`，正式 runner 与原始 ONNX 不改。

## 2. 假设与改动

参考正式 runner 中 `third_party/custom_development_code/fusion_pass/AttentionFusionPass`：遍历 GE 图的末端 `Transpose`，沿数据边回溯 `BMM → Softmax → Add(mask) → BMM(Q,K)`，完整结构符合才替换。移除 BGE `layer.N` 名字及固定 24 层要求。检查 Q/K/V 的转置排列、BSND reshape 头数/宽度、Q/K 同源缩放链及其取最后一维的 `StridedSliceD` 参数、`SelectV2` 的 BOOL 屏蔽条件及 `-FLT_MAX` 分支、BMM 无转置/偏置、Softmax 沿末轴、FP32 描述符和待删除节点单使用者。命中的子图数由实际图决定；0 个命中时不改图。该模式要求输入 keep-mask 为二值、双向 padding mask；它不覆盖因果 mask 或其他 attention 结构。

## 3. 验收与比较条件

构建新 SO，保留 OPT-019 的旧 SO 和数据；在原始 BGE 上确认逐结构命中 24 处且优化后 24 个 FIAS 的 Q/K/V/输出为 FP16、mask 为 BOOL。五例业务输入继续对 CPU 和 expected Top10 比较。构造全部节点改名与单层结构不匹配的等价 ONNX 变体，验证不依赖名称和层数。本项未独立重测吞吐，因此不把 OPT-019 的性能数字写作本项新增收益。
