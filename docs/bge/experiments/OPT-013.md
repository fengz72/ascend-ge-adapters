# OPT-013：原图FP32十二实例、每算子12|24核

## 1. 身份与状态

2026-10-27分配。父配置为100本机原图FP32、GE mode=0、8实例、每算子`12|24`核上限；目标配置改为12实例，其余图、runner、输入、精度与设备身份不变。状态：固定case两轮搜索通过，**不接纳**。

## 2. 问题与假设

10实例首轮586.098QPS，未高于8实例正式中位586.387QPS。12实例可帮助区分10实例偶然波动和并发平台，也可能因调度竞争进一步下降。

## 3. 实现与回退

仅实例数改为12。保持原始30个Slice图、FP32、GE mode=0、`aicore_num=12|24`、无自定义融合插件。回退到已验收的8实例配置。

## 4. 比较条件

100逻辑设备2、固定`case-0000`、batch1，每实例单在途，预热10次。计时包含H2D、GE完成同步和全量D2H，无capture/profiling；搜索至少30秒/2000请求。与8实例正式三轮及10实例单轮搜索比较时注明测量级别。

## 6. 分析与决策

两轮分别30.001420/30.000010秒、17934/17986窗口成功、0错误，计划/输入/二进制身份、独立性能重算和作业释放检查通过。中位比8实例正式中位高2.09%，仍低于预设3%且小于8实例三轮3.03%相对极差；16实例两轮回落。p99升高，且本项未做五例全量输出压力及正式稳定性，故**不接纳**。HBM仍充足，停止原因是QPS平台/回落而非容量耗尽。
