# OPT-001：Cube FP16输入、FP32输出

## 1. 身份与状态

2026-10-26；主控分配，SE/开发实现或配置，测试独立核对。父版本为原FP32全核单实例，GE Session mode=0，逻辑设备10（NPU5/Chip0，PCI0000:89:00.0）。不接纳：搜索吞吐观察下降10.28%，未超过基线约11.45%的轮间相对极差，未证明收益。

## 2. 问题与假设

口径同 [README.md](README.md) 第 2 节。本项检验 Cube FP16 输入、FP32 输出能否提高包含输入输出搬运的成功吞吐；不由算子数量或数据类型推算收益。

## 3. 实现与回退

原始模型和外部IO不变，GE precision_mode=cube_fp16in_fp32out。199个MatMul/BMM实际半精度输入、FP32输出，196个F32→F16 Cast图节点；这不是kernel启动次数。49个LayerNorm、25个Softmax及5个LpNorm保持FP32，累加精度未由图证明。

源模型/权重、样例、expected 与阈值不变（口径见 [README.md](README.md) 第 2 节）。测量 binary SHA256=8efca50a62a7f569032345259d6e7813da428023903e4674d77de92bc7ac630d。回退到原 FP32、全核、instances=1、不加载插件。

## 4. 比较条件

口径同 [README.md](README.md) 第 2 节。本节为 30 秒且 ≥2000 请求的搜索，capture/profiling=false；压力采集另做，采集数字不作性能值；相对差值只是搜索观察，无统计显著性声明。

## 6. 分析与决策

数值正确且内部降精度已生效，但这批短序列B1搜索未显示吞吐收益；没有执行三轮正式候选验收和10分钟候选稳定性。

不接纳：搜索吞吐观察下降10.28%，未超过基线约11.45%的轮间相对极差，未证明收益。汇总规则见 [README.md](README.md) 第 2 节。
