# OPT-003：CANN自动FP16混合精度

## 1. 身份与状态

2026-10-26；主控分配，SE/开发实现或配置，测试独立核对。父版本为原FP32全核单实例，GE Session mode=0，逻辑设备10（NPU5/Chip0，PCI0000:89:00.0）。不接纳：搜索吞吐观察下降12.94%，未显示收益。

## 2. 问题与假设

口径同 [README.md](README.md) 第 2 节。本项检验 CANN 自动 FP16 混合精度能否提高包含输入输出搬运的成功吞吐；不由算子数量或数据类型推算收益。

## 3. 实现与回退

使用allow_mix_precision_fp16，不加载融合插件。199个矩阵及24个Gelu输入输出FP16，49个LayerNorm及24个attention Softmax保持FP32；gate Softmax与最终score内部为FP16，外部score转回FP32。归一化中有两组LpNorm/Maximum/Div变为FP16；其它三组仍FP32。

源模型/权重、样例、expected 与阈值不变（口径见 [README.md](README.md) 第 2 节）。测量 binary SHA256=8efca50a62a7f569032345259d6e7813da428023903e4674d77de92bc7ac630d。回退到原 FP32、全核、instances=1、不加载插件。

## 4. 比较条件

口径同 [README.md](README.md) 第 2 节。本节为 30 秒且 ≥2000 请求的搜索，capture/profiling=false；压力采集另做，采集数字不作性能值；相对差值只是搜索观察，无统计显著性声明。

## 6. 分析与决策

仅对给定五例通过，不能推广至极小范数/边界排名等输入；1e-12下限的FP16表示存在下溢风险，未从dump直接读取常量payload，不声称实测为0。未进行三轮正式候选性能或10分钟候选稳定性。

不接纳：搜索吞吐观察下降12.94%，未显示收益。汇总规则见 [README.md](README.md) 第 2 节。
