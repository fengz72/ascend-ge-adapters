# OPT-006：原FP32全核四实例闭环并发

## 1. 身份与状态

2026-10-26；主控分配，SE/开发实现或配置，测试独立核对。父版本为原FP32全核单实例，GE Session mode=0，逻辑设备10（NPU5/Chip0，PCI0000:89:00.0）。暂作为中间有效候选；最终接纳由冻结复测和稳定性决定。

## 2. 问题与假设

口径同 [README.md](README.md) 第 2 节。本项检验原 FP32 全核四实例闭环并发能否提高包含输入输出搬运的成功吞吐；不由算子数量或数据类型推算收益。

## 3. 实现与回退

与单实例FP32基线相同图/精度/全核，仅instances=4；每实例独立图、stream及输入输出缓冲，仍业务batch1、每实例一个在途请求。

源模型/权重、样例、expected 与阈值不变（口径见 [README.md](README.md) 第 2 节）。测量 binary SHA256=8efca50a62a7f569032345259d6e7813da428023903e4674d77de92bc7ac630d。回退到原 FP32、全核、instances=1、不加载插件。

## 4. 比较条件

口径同 [README.md](README.md) 第 2 节。本节为 30 秒且 ≥2000 请求的搜索，capture/profiling=false；压力采集另做，采集数字不作性能值；相对差值只是搜索观察，无统计显著性声明。

## 6. 分析与决策

30.001677326秒窗口11107成功+3尾部，0错误，搜索QPS370.212634、p99 11.448209ms。setup后HBM约5726MB。搜索吞吐观察+111.16%，延迟同步增加；无SLA上限，继续八实例。

暂作为中间有效候选；最终接纳由冻结复测和稳定性决定。汇总规则见 [README.md](README.md) 第 2 节。
