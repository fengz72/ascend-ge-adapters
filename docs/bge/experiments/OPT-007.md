# OPT-007：原FP32全核八实例闭环并发

## 1. 身份与状态

2026-10-26主控分配，状态：已完成device10八实例正确性与纯性能搜索；父基线原FP32单实例175.321044QPS。用户此前明确核数和多实例也是调优手段，FP16/融合未显示吞吐收益，双实例已有约54%搜索提升，四实例已完成有效搜索，八实例也已完成关联压力与纯性能搜索。设备10，同一物理芯片，不使用其它卡。当前作为中间候选，最终交付配置尚未冻结。

## 2. 问题与假设

已测单实例矩阵半精度及融合搜索尚未证明收益；短文本B1可能存在细粒度算子/Host/设备调度空隙，多图独立stream并发可能提高设备利用和成功吞吐。此为待验证假设，未采profiling不写确定瓶颈。无p99硬上限，但必须报告延迟变化。

## 3. 实现与回退

使用相同冻结8efca50a二进制和原FP32图，只将instances从1改8，每实例独立图ID/stream/输入输出缓冲，单实例一个在途请求；统一全局等概率case序列，不改变业务batch1。原模型/权重/dtype不变，不加载融合插件，tcmalloc默认不变。回退instances1。

## 4. 比较条件

同device10全核、同5样例及验收门槛，计时H2D+desc+GE完成+全量D2H；先2000请求输出关联压力(每实例每case≥20、每case10轮预热)，然后30秒/2000搜索。若有收益再冻结三轮60秒/10000、交错基线复测及最终10min稳定性；p99只观察、不声称SLA。
