# OPT-019：24 层 FusedInferAttentionScore 融合

## 1. 身份与状态

2026-10-29 完成。父配置为 100 机器原始 BGE ONNX、GE mode=0、`force_fp16`、每算子 `12|24` 核、10 实例。基于 OPT-018 已通过的首层 pass，将 24 个 Transformer attention 层分别改写为 `FusedInferAttentionScore`。隔离工作副本为 `merge-review-20261029`，正式 runner 和原始 ONNX 不改。当前状态：五例业务精度与两种回放性能均通过，**接纳为当前实验配置的优化点**；当时正式 runner 集成尚未进行；2026-10-30 已归档结构匹配实现与可选入口，默认配置仍未启用。

## 2. 假设与改动

假设 24 次融合减少小序列下的 QK、Softmax、AV 算子与中间张量开销，可能改善吞吐；首层 30 秒探索轮没有证明收益，因此本项必须独立测量。沿用 OPT-018 的双向 BOOL padding mask、BSND Q/K/V、16 头、D64、`scale=0.125`、动态 B/S 与 `force_fp16` 精度路线。所有 24 层必须精确匹配且全部替换，否则拒绝图；不允许仅部分命中就计为全层候选。

## 3. 验收与比较条件

先检查最终 GE 图中 24 个 FIAS 节点均存在且其 Q/K/V 和输出是 FP16，运行五条业务样例，与 CPU 全分数及 `expected_outputs.json` Top10 ID、顺序、分数比较。含 padding 和全 0 mask 合成样例验证边界。正确性过关后，同一空闲物理 NPU、相同 10 实例及核数、无 profiling，分别对固定 `case-0000` 和五例等概率随机回放测原图与候选。计时包括 H2D、描述符、GE 同步和完整 D2H。每项计划 60–90 秒、至少 10000 请求，原图与融合交替运行两轮；先检查相邻轮波动，再判断收益。
