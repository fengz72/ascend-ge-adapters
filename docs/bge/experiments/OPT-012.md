# OPT-012：原图FP32十实例、每算子12|24核

## 1. 身份与状态

2026-10-27分配。父配置为100本机原图FP32、GE mode=0、8实例、每算子`12|24`核上限；目标配置改为10实例，其余模型、图、runner、输入、精度与设备身份不变。状态：固定case搜索通过，**不接纳**。适用本次明确追加的实例数探索；历史总预算继续记录，但不再作为本次硬性停止条件。

## 2. 问题与假设

8实例是已验收的可行点，不是经证实的吞吐上限。增加到10实例可能提高芯片利用率和成功吞吐，也可能因调度竞争或Host/HBM消耗带来下降；依据同机同case实测判断。

## 3. 实现与回退

仅将实例数从8改为10；保持原始30个Slice图、FP32、GE mode=0、`aicore_num=12|24`、无自定义融合插件。回退至8实例已验收配置，不覆盖既有结果。

## 4. 比较条件

100逻辑设备2、固定`case-0000`、batch1，每实例单在途、预热10次。H2D、描述符、GE完成同步及40448字节D2H纳入计时，无capture/profiling。起点8实例为2026-10-27三轮正式结果；10实例先做至少30秒/2000请求的筛选，若入选须同口径复测并做五例正确性/稳定性。两者测量级别不同，不以筛选QPS直接算正式交付收益。
